# Offensive-Security-and-Penetration-Testing

## Overview

This repository contains five practical cybersecurity laboratories covering web application security testing, command injection, reverse-shell techniques, DNS and SMB enumeration, anonymity technologies, and password security assessment.

The laboratories were completed as part of hands-on cybersecurity training using Kali Linux, intentionally vulnerable applications, security-testing tools, and controlled laboratory environments.

The work demonstrates practical application of offensive-security concepts, security-tool usage, vulnerability identification, enumeration, technical analysis, and security documentation.

---

## Labs

### Lab 1 — Web Application Security Testing

This laboratory focuses on assessing web application security using **Burp Suite** and **OWASP ZAP**.

Topics include:

- HTTP request and response analysis
- Traffic interception
- Web application crawling
- Endpoint discovery
- Security scanning
- Fuzzing
- Security header analysis
- Cookie security
- XSS assessment
- Security findings and recommendations

---

### Lab 2 — Command Injection and Reverse Shell

This laboratory focuses on understanding command injection vulnerabilities and demonstrating reverse-shell concepts using **DVWA** and **Netcat** in a controlled environment.

Topics include:

- Command injection
- Input validation weaknesses
- Command execution
- Netcat
- Reverse-shell concepts
- Linux command execution
- User and system information gathering
- Security risks and mitigation

---

### Lab 3 — DNS and SMB Enumeration

This laboratory focuses on DNS analysis and SMB enumeration using command-line security tools.

Topics include:

- DNS enumeration
- `nslookup`
- `host`
- `dig`
- DNS record analysis
- SMB enumeration
- `enum4linux`
- Network-service enumeration
- Security risks associated with exposed services

---

### Lab 4 — Tor and Proxychains Anonymity Testing

This laboratory examines Tor-based traffic routing and Proxychains configuration, with emphasis on the capabilities and limitations of anonymity technologies.

Topics include:

- Tor
- Proxychains-ng
- SOCKS5 proxy configuration
- IP address verification
- Tor exit nodes
- Tor circuit behavior
- DNS proxying
- Browser-based testing
- DNS leak considerations
- Limitations of Tor for active scanning

---

### Lab 5 — Password Security with John the Ripper

This laboratory focuses on password security assessment and password-hash auditing using **John the Ripper**.

Topics include:

- Password hashes
- Hash identification
- Wordlist attacks
- Custom wordlists
- Brute-force testing
- NTLM password auditing
- Rule-based attacks
- Password complexity
- Password-security analysis

The password-auditing exercises used laboratory data for educational purposes.
