# Penetration Testing and Security Assessment

## Overview

This repository contains practical cybersecurity laboratory work focused on penetration testing, security assessment, network forensics, web application security, system enumeration, anonymity technologies, and password security.

The projects were completed as part of hands-on cybersecurity training using controlled laboratory environments, vulnerable applications, Linux-based security tools, and authorized testing scenarios.

The work demonstrates the practical application of cybersecurity concepts through security testing, traffic analysis, vulnerability identification, command-line tools, security assessment, and technical documentation.

---

## Projects

### 1. Network Forensics and Web Security Testing

**File:** `Network-Forensics-and-Web-Security-Testing.pdf`

This project focuses on analyzing network traffic and assessing web application security using forensic and security-testing techniques.

Topics demonstrated include:

- Wireshark network traffic analysis
- Identification of suspicious network activity
- HTTP traffic analysis
- Analysis of potential SQL injection indicators
- Web application traffic investigation
- Attack timeline reconstruction
- Forensic reporting
- Burp Suite
- OWASP ZAP
- HTTP request and response interception
- Web application spidering
- Security scanning
- Fuzzing
- HTTP security headers
- Cookie security
- Cross-site scripting (XSS) assessment
- Security findings and recommendations

The project demonstrates the ability to examine network and web application activity, interpret security-related traffic, document findings, and communicate potential vulnerabilities.

---

### 2. Command Injection, DNS and SMB Enumeration

**File:** `Command-Injection-DNS-and-SMB-Enumeration.pdf`

This project focuses on command injection, reverse-shell concepts, DNS analysis, and SMB enumeration within controlled cybersecurity laboratory environments.

Topics demonstrated include:

- DVWA command injection
- Input validation weaknesses
- Command execution
- Netcat reverse-shell concepts
- Linux command execution through a vulnerable application
- User and system information gathering
- DNS analysis
- `nslookup`
- `host`
- `dig`
- DNS record queries
- SMB enumeration concepts
- Security assessment and mitigation
- Identification of potential security risks

The command-injection exercises were performed against a deliberately vulnerable laboratory application.

The project also demonstrates how enumeration techniques can be used to gather information about network services and identify areas requiring additional security controls.

---

### 3. Tor, Anonymity and Password Security

**File:** `Tor-Anonymity-and-Password-Security.pdf`

This project focuses on privacy technologies, traffic routing, password security, and password auditing within controlled environments.

Topics demonstrated include:

- Tor service configuration
- Proxychains-ng
- SOCKS proxy configuration
- Proxy-based traffic testing
- IP address masking
- DNS proxying concepts
- Tor circuit behavior
- Browser-based Tor testing
- Security considerations associated with Tor exit nodes
- John the Ripper
- Password hash auditing
- Wordlist attacks
- Custom wordlists
- Brute-force password testing
- NTLM password auditing
- Rule-based password attacks
- Password security analysis

The Tor exercises demonstrate traffic routing through a configured Tor path. They do not claim that Tor provides complete anonymity.

Password-cracking exercises were performed using deliberately created laboratory passwords and hashes for educational purposes.
